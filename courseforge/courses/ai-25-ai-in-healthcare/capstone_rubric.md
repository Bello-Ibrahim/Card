# Capstone Rubric: Evaluation of an AI Health Tool

## Task
Write an evaluation of an AI health tool covering clinical value, risks and a safe implementation plan. Choose a hypothetical tool, or a real tool described only from its public documentation. You build the evaluation in three steps: intended use and clinical value (L12), risk assessment (L13) and the implementation plan with a recommendation (L14). Use only public or synthetic information. Never include identifiable patient data, and do not give clinical advice: treat the tool as decision support under clinician oversight.

## Deliverables
- A written evaluation of about 1,500–2,500 words using the 10-section template from L12:
  1. Tool description and intended use
  2. Clinical value: problem, outcome, for whom, compared with current practice
  3. Evidence: level of evidence and performance claims (synthetic figures labelled as synthetic; real figures with their public source)
  4. Data and privacy
  5. Bias and equity
  6. Risks and failure modes
  7. Workflow and accountability
  8. Regulatory position: questions marked "to check locally"
  9. Safe implementation plan
  10. Recommendation
- A risk table with at least six risks covering clinical safety, bias and equity, privacy, security, workflow and accountability, each with likelihood, severity, mitigation and owner.
- A list of sources: links to public documentation for a real tool, or a note that the tool is hypothetical.

## Submission Checklist
- I evaluated a hypothetical tool, or a real tool described only from its public documentation, and I listed my sources.
- My evaluation uses all 10 sections of the L12 template.
- My intended use statement names the patients, setting, user and decision supported.
- My clinical value section names a measurable outcome and compares the tool with current practice.
- Every performance figure has a public source or is labelled as synthetic.
- My risk table has at least six risks across all six areas, each with a mitigation and a named owner.
- I discussed bias and dataset shift for at least one named patient group or care setting.
- My regulatory questions are marked "to check locally" and name who I would ask.
- My implementation plan includes silent mode, monitoring with an equity measure, stop criteria and a withdrawal plan.
- My recommendation is clear and follows from my analysis.
- My evaluation contains no identifiable patient data and no clinical advice.
