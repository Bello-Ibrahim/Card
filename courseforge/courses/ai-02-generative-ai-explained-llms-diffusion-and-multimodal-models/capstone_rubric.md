# Capstone Rubric: Three-Tool Comparison Report

## Task
Test three generative AI tools on the same real-world task from your work or studies, and write a 2–3 page comparison report that explains the results with what you learned about how each type of model works. You design the test in L10 (capstone step 1), run it in L11 (capstone step 2) and write the report in L12 (capstone step 3). Remove all personal and confidential data from your input before you use any tool, or use a realistic hypothetical version.

## Deliverables
- A test plan: the task, the exact prompt, the input (with personal data removed) and a scoring rubric with 4–6 criteria and their weights, decided before testing.
- A results folder with the three saved outputs and a screenshot of each test.
- A log table with one row per tool: tool name, version or model shown (or "not shown"), date, settings changed, scores and notes.
- A 2–3 page report with six parts: task, method, results table, strengths and failures, recommendation, and limits of the test.

## Submission Checklist
- I tested the same task, input and prompt in three generative AI tools.
- My rubric had 4–6 criteria, and I decided it before I saw any output.
- I removed all personal and confidential data from my input.
- I saved every output with a screenshot, and my log shows the tool version (or "not shown"), the date and any settings I changed.
- I scored each output straight away against my rubric.
- My report has six parts: task, method, results table, strengths and failures, recommendation and limits.
- I linked each failure to a likely cause, using how that type of model works.
- My recommendation is for this task only and names the human checks still needed.
- My report is 2–3 pages and written in my own words.
