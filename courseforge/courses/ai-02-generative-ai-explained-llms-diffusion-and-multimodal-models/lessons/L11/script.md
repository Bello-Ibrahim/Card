# L11 Running the Comparison | Presenter Script

Course: AI-02 · Video: 5 min · Words: 689

## Hook
Your task, input, prompt and rubric are ready. Now comes the part that feels easy, running the tests. But small mistakes here, like one changed word or a lost output, can make the whole comparison unfair. Let's run it carefully.

## Explain
In the last lesson, you designed a fair test. This is capstone step two. Running it well is about discipline and records. You follow the same routine for every tool.

Before you start, open your capstone document with the fixed prompt, the input and the rubric. Create a results folder, with one folder inside for each tool. And create a log table, with the tool, the version shown, the date, any settings you changed, the output file, the scores and notes.

Then, for each tool. Start a new, empty chat, so earlier conversations do not affect the result. Write down the version the tool shows, or not shown. Note any settings you change. Paste the exact prompt and input, with no improvements.

Save the complete output, and take a screenshot. Then score the result straight away, before you open the next tool. That way you judge each tool against your criteria, not against another tool. Finally, note anything surprising, like a refusal or a long wait.

Which three tools? For a text task, you might use Claude or ChatGPT, Google AI Studio and a third free chatbot. For an image task, use three free image generators. And for photos or audio, choose tools that accept uploads.

It is like a science experiment in a school laboratory. You follow the method exactly, write down every measurement when you take it, and label every sample. If you try to remember the results the next day, nobody can trust the conclusion.

## Demonstrate
Let's watch a real run. Sione is a tourism officer at a visitor centre in Suva. His task is to turn a public information sheet about a nature park into six frequently asked questions for the centre's website.

He opens his capstone document and shows the fixed prompt. It asks for six questions and short answers for first-time visitors, using only the text, and without inventing missing information.

He opens the first tool, a free chatbot, and starts a new chat. He reads the model name shown on screen and types it into his log, with today's date. Then he pastes the prompt and the information sheet, and runs it.

He copies the full answer into a file called tool one output, and takes a screenshot. Then he scores it straight away. Accuracy four, clarity five, structure five, effort to fix four. His note says one answer adds a parking fee that is not in the sheet.

Next, he opens Google AI Studio, starts a new prompt, and checks that the temperature is at its default value. He records that in the log. Then he repeats the same steps, and saves tool two output.

He runs the third tool in exactly the same way, and saves tool three output. Now his log has three complete rows.

The scores differ, but Sione does not choose a winner yet. First, he checks that every row has a date, a version entry, a saved output and all the scores. The analysis comes next.

A common mistake is to run all three tools first, and score them later from memory, or side by side. Then a good output looks worse next to the best one, and details are forgotten. Score each output against your rubric straight away.

## Recap
Let's recap. First, use a new chat for each tool, paste the exact same prompt and input, and record any settings you change. Second, save every complete output, with the tool name, the version shown and the date. Third, score each result against your rubric straight away, before you look at the next tool.

## CTA
This is capstone step two. In the exercise below, run your task in three tools, save each output with the date and version, and score each one with your rubric. It takes about forty-five minutes. In the final lesson, you bring it all together by writing the comparison report. See you there.
